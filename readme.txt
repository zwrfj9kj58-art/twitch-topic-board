---------------------------------OBSで確認してみよう！
① OBSへの登録方法
1. 配信画面表示用 (オーバーレイ)
ブラウザで一度index.htmlを開き、URLをコピーしてください。
(htmlファイルをテキストデータで開いてしまう場合は右クリックから[プログラムから開く]でブラウザを選択してください。Macの場合は[このアプリケーションで開く]になります)

OBSのソース一覧に「ブラウザ」を追加し、URLをペーストし「?mode=source」を末尾につけてください。
（この時ローカルソースのチェックは外してください。）

2. 管理操作用 (コントローラー)
OBSの上部メニューの 表示 ➔ ドック ➔ カスタムブラウザドック を開き、以下のドック名とURLを登録します：

ドック名: Twitchお題ボードやYouTubeお題ボードなどお好きにつけてください
URL: 上記同様にブラウザからコピーしたURLを貼り付けます。（?mode=sourceは付けないように）

これにより、OBSの画面の端にコントローラーを埋め込み、
配信中にポチポチ操作したりキーボードのホットキーでお題を切り替えることができます！



--------------------さらにリスナーさんからのお題を自動取得したい場合（手動で追加もできるので無理に設定しなくてもOK）

※こちらTwitchの場合は特に設定は必要ありません。
自分のチャンネルIDを入力し接続されれば使用可能です。


💬 YouTube版チャット連携機能 (Google APIキー使用)
手動管理に加え、Google Data API を使用して配信中のYouTube Liveチャットからお題を自動取得する機能も実装しています！

⚙️ 設定手順と使い方

🌠Google API キーの用意

Google Cloud Console にアクセスし、プロジェクトを作成します。
「ライブラリ」から YouTube Data API v3 を有効化します。
「認証情報」から APIキー を作成します（作成したAPIキーはコピーしておきます）。

🌠お題ボード（管理画面）での設定

コントロールパネルの 「YouTubeチャット連携機能」 カードを開きます。
Google API キー: 取得したAPIキーを入力します（キー漏洩防止のため入力内容は非表示マスキングされます）。
配信URL または ビデオID: 配信予定のYouTube配信URL（例: https://www.youtube.com/watch?v=xxxx または https://youtube.com/live/xxxx）を入力します。


呼び出しコマンド: リスナーがお題を投稿する際のコマンド（例: !お題, !topic）をカンマ区切りで入力します。
チャット連携を有効化 のスイッチをオンにします。


🌠自動取得の仕組み

連携が成功すると、接続状態が 🟢 チャット同期中 に変わります。
リスナーが配信チャットで !お題 おすすめのご飯は？ のようにコメントすると、自動的にお題ボードの 「リスナーからの話題」 枠にお題と投稿リスナーの名前が追加されます！



-----------------------------------------------使用について

1.商用利用の可否：ご利用いただいて問題ありません
2.改変の可否：CSSを弄れるよ！と言う方はお題の内容や背景、色などを自分好みにカスタマイズ可能です！アイコンの画像はお手製ですが、差し替えて使用していただいて構いません！
3.クレジット表記：任意ですが、もし表記してくださる場合はHNやXのURLなど掲載していただけると幸いです。
4.禁止事項： 二次配布（再配布）、自作発言、公序良俗に反する配信での使用などは禁止させていただいております。
